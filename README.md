# easyglider

Onboard flight software for a fixed-wing Easy Glider UAV used in my thesis on UAV control. A Raspberry Pi companion computer runs path-following controllers (MAVSDK, C++) and streams data, while a Pixhawk running PX4 handles low-level flight control.

Built on Filipe Cavalheiro's work: [Filipe-Cavalheiro/MAVSDK](https://github.com/Filipe-Cavalheiro/MAVSDK/tree/main).
